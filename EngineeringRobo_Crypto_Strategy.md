# Crypto strategy

`EngineeringRobo_Crypto_Strategy.pine` is the cleaned, standalone version of the user-supplied script. Paste the plain file into Pine Editor (without Markdown bold markers, HTML entities or escaped multiplication signs).

It uses the current chart symbol and timeframe, with no BTC prices, fixed contract quantity, sessions or higher-timeframe requests. Signal/risk ATR lengths count chart bars. Default allocation is10% of current equity; change it in Strategy Properties. TradingView rounds quantities subject to the symbol's contract rules; an allocation below minimum tradable size or insufficient margin can still prevent fills. Shorts model perpetual/margin trading; cash spot accounts generally cannot short, so select Long Only there.

Confirmed Supertrend flips enter in the normal direction. Opposite flips reverse when enabled; single-direction modes close on the forbidden opposite direction. When reversal is disabled, opposite signals leave existing positions to their bracket exits. Turning the master switch off stops new signal actions but retains existing protective exits. With both SL/TP disabled and opposite closing disabled, a position has no scripted exit.

ATR distances are frozen only on submitted entries, rounded upward to at least one symbol tick, and submitted as relative loss/profit ticks alongside the entry. Separate long/short exit IDs anchor each bracket to its actual fill. Fill recalculation is disabled to avoid historical repeated signal entries and full-candle lookahead after simulated intrabar fills. Entries use signal-bar close processing as requested. Extreme projected non-positive long stops/short targets are rejected with an orange marker; actual exchange execution is not simulated exactly.

Defaults include0.07% commission per side and2ticks slippage; set the actual venue costs in Properties. Tick slippage represents a different price amount for each symbol. Standard time-based candles are recommended for backtests; synthetic chart prices and incomplete Bar Magnifier coverage can distort fills. Native Pine compilation, broker integration and profitability across coins/timeframes have not been verified. The earlier Python studies tested15mBTC proxy data only and do not validate this strategy on other markets.

Buy/sell labels and alert() calls mark signals, including signals ignored because of direction/position settings. Executed trades appear through TradingView strategy order markers and the trade list. Create order-fill alerts to automate executions, using `{{strategy.order.alert_message}}`; signal alerts alone do not mean an order filled. Entry/SL/TP plots show positions observed at calculation time; a same-bar round trip can appear only in the trade list/order markers. No alertcondition() is used because it does not create strategy alert triggers.
